# Findly — Searchable Listing Dashboard

CodeNova Frontend Development Internship — Task 4.

## Features
- Live search by product name, category, and description
- Category filters: Technology, Style, and Living
- Sorting by price (low/high) and product name
- Product cards with quick-view interaction
- Result count, clear filters, and empty-results state
- Responsive desktop, tablet, and mobile layout
- Ctrl/⌘ + K keyboard shortcut to focus search

## Built with
HTML5, CSS3 (Grid, Flexbox, media queries), and vanilla JavaScript.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — sample catalogue and interactive functionality

## Run locally
Open `index.html` in a browser. No installation or paid service is needed.

## Publish with GitHub Pages
Create a public repository, upload these files to the root, then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Wait for GitHub Pages to finish building.
